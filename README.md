# เกมต่อภาพรถยนต์ (Jigsaw Puzzle)

เกมต่อภาพสำหรับเล่นบนเบราว์เซอร์ด้วย HTML, CSS และ JavaScript โดยใช้ภาพ `car.jpeg`

## วิธีเล่น

1. ดับเบิลคลิก `PLAY-GAME.bat` เพื่อเริ่มเว็บเซิร์ฟเวอร์ในเครื่องและเปิดเกมในเบราว์เซอร์ปกติ (ไม่เปิด `index.html` โดยตรงหรือใน VS Code Preview)
2. เลือกระดับความยาก: ง่าย 12 ชิ้น, ปกติ 20 ชิ้น หรือยาก 36 ชิ้น
3. ลากชิ้นส่วนจากถาดมาวางบนตำแหน่งที่ถูกต้องบนกระดาน หรือแตะค้างแล้วลากหากเล่นบนมือถือ
4. กด **เริ่มเกมใหม่** เพื่อสุ่มชิ้นส่วนและเริ่มจับเวลาใหม่

บนจอ PC พื้นที่เกมจะแสดงอยู่ในหน้าต่างเดียวโดยไม่ต้องเลื่อนหน้า ส่วนถาดชิ้นส่วนสามารถเลื่อนภายในถาดได้

บนมือถือ หน้าเกมจะจัดเรียงกระดาน รูปตัวอย่าง และชิ้นส่วนให้เหมาะกับหน้าจอแนวตั้งหรือแนวนอน พับเมนู **เพลงและเสียง** เพื่อเพิ่มพื้นที่เล่น แล้วแตะค้างบนชิ้นส่วนและลากไปวางบนกระดานได้ หมุนจอระหว่างเล่นได้โดยชิ้นที่วางถูกแล้วจะยังคงอยู่ หน้าจอมือถือใช้สกรอลล์เพื่อดูพื้นที่เล่นที่เหลือ และยึดกระดานไว้ด้านบนขณะเลือกชิ้นส่วน

## เพลงและเสียง

- เลือกเพลงจาก 3 วิดีโอ YouTube หรือกด **สุ่มเพลง** เพื่อสุ่มรายการ
- หลังเลือกหรือสุ่มเพลง ให้รอจนปุ่มเปลี่ยนเป็น **เล่นเพลง** แล้วกดปุ่มเพื่อเริ่มเสียง เบราว์เซอร์ต้องรับการกดจากผู้ใช้ก่อนจึงอนุญาตให้เล่นเสียงได้
- ปรับระดับเสียงเพลงและเสียงตอนวางชิ้นส่วนได้แยกกัน
- เพลงเล่นผ่าน YouTube Player จึงต้องเชื่อมต่ออินเทอร์เน็ตและเปิดเกมผ่าน `PLAY-GAME.bat` (การเปิด `index.html` โดยตรงอาจทำให้ YouTube แจ้ง Error 153 และ VS Code Preview อาจไม่รองรับการเล่นวิดีโอ) หากเครื่องเล่นแจ้งข้อผิดพลาด ให้กด **เปิดใน YouTube**
- อย่าปิดหน้าต่าง PowerShell ที่เปิดขึ้นระหว่างเล่นเกม เพราะเป็นเว็บเซิร์ฟเวอร์สำหรับเพลง เมื่อเล่นเสร็จให้กด `Ctrl+C` เพื่อปิดเซิร์ฟเวอร์

เกมไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม โดย `index.html`, `styles.css`, `game.js` และ `car.jpeg` ต้องอยู่ในโฟลเดอร์เดียวกัน
